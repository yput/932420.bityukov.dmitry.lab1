# Задание:
## Создать HTML-страницу «О себе», которая содержит следующие элементы:
<ul>
  <li>header – шапка с именем/фамилией студента и заголовком страницы.</li>
  <li>main – основной контент.</li>
  <li>Две секции section: «Навыки» (маркированный список) и «Проекты»
(нумерованный список из 3–4 пунктов).</li>
  <li>aside – боковая панель с краткой информацией (например, «Любимые
технологии»).</li>
  <li>footer – подвал с копирайтом и годом.</li>
  <li>Одно изображение (портрет/аватар) с атрибутами src, alt, width, height.</li>
  <li>Форма обратной связи: поля «Имя» (type="text"), «Email» (type="email"),
«Сообщение» (<textarea>), кнопка отправки. У всех полей – атрибуты name и
placeholder.</li>
</ul>
  
## Вариант 6. Тема «Любитель кино и сериалов».
В «Навыках» – навыки, связанные санализом кино (например, сценарный анализ, понимание операторской работы, монтаж). 
В «Проектах» – 3–4 фильма/сериала, для которых вы бы написали альтернативный сценарий или сделали фанатский трейлер. 
В aside – любимый режиссёр или жанр. 
Цветовая гамма: чёрно-золотая (в духе кинопремий)
